# ChatGPTサポートの実態 — 公開記録

OpenAI Supportとのやり取りについて、利用者の質問、実際の回答、未回答事項とその後の対応を時系列で残す利用者側の記録です。

## これまでの経緯から読む

[これまでの経緯・公開資料・未掲載範囲](HISTORY.md) に、2026年5月以降の旧Case索引、8月の公開メール証拠、9月13日の記録への案内をまとめています。以前の記録は [openai-trust-audit](https://github.com/lucidity3k/openai-trust-audit) と [公開中のPR #2](https://github.com/lucidity3k/openai-trust-audit/pull/2) にあります。

これまでの主な照会内容は、有料サービスの利用枠・機能表示、個別の利用・返金記録、返金判断の根拠、誤回答の訂正、Case間の未回答事項の引継ぎ、既提出情報の再提示負担です。旧記録の一部はCase索引や利用者報告の段階で、全サポート履歴の原文が公開済みではありません。

このリポジトリは、まず従前の記録を案内する履歴から開始します。新しい往復は、その履歴に続けて日付・Case・出典を付けて追加します。
